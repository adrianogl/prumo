Seus PRs no prumo, sem abrir o GitHub.

O PRumo fica no canto da tela e acompanha os PRs que você abriu e os reviews pedidos a você. Avisa quando a CI termina, quando aprovam e quando chega comentário. Para CI quebrada, conflito e comentários, abre o Claude Code já na branch do PR.

Tudo o que importa numa linha.

O ícone na barra mostra quantos reviews esperam por você, com um ponto vermelho quando alguma CI sua está falhando. O popover tem duas abas.

  • Meus PRs: os PRs abertos que você criou, em qualquer repositório.
  • Revisar: os PRs em que pediram o seu review, com quem pediu, há quanto tempo e o tamanho do diff.
  • Bolinha de status e badges de CI (checks que passaram e o nome do que falhou), aprovações, alterações pedidas, draft, conflito e comentários.
  • Clique na linha abre o PR. O menu ⋯ ou o botão direito trazem as ações do Claude, abrir no navegador e copiar link.
  • Sem rede, sem token válido ou com limite da API, a lista continua com os últimos dados e um aviso do que está acontecendo.

CI quebrou? O Claude Code abre na branch certa.

Um clique abre o terminal numa worktree do PR, com o prompt pronto. Seu clone principal não muda de branch.

QuandoOnde clicarO que o Claude faz
Review pedido a vocêRevisar com Claude no menu ⋯Roda o seu comando de review, /code-review <n> por padrão.
CI falhando no seu PRcorrigir no badge, no menu e na notificaçãoLê o log do job que falhou, encontra a causa e corrige.
PR em conflitoresolver no badge e no menuFaz merge da branch base, resolve os conflitos, roda os testes e commita.
Comentários ou alterações pedidasresolver no badge e no menuLê os comentários, aplica o que fizer sentido e resume o que mudou e o que ficou de fora. Não responde nem resolve conversas no GitHub.
  • Encontra o clone do repositório em ~/Code pelo remote. Se não achar, pergunta a pasta uma vez e confere se ela é mesmo daquele repositório.
  • Cria a worktree em ~/Code/.prumo-worktrees/<repo>-<n>. Para corrigir CI, conflito e comentários usa a branch real do PR, sem resetar commits seus; para revisar ou em PR de fork, uma worktree destacada.
  • Respeita a sua função ou alias claude do .zshrc.
  • Nenhum texto do PR (título, nome de job, branch) é digitado no terminal ou montado numa linha de shell: o terminal só roda um script do próprio app.
  • Apaga a worktree quando o GitHub confirma que o PR foi fechado ou mergeado, e só se ela estiver limpa e sem commits por enviar.
  • Prompts, flags do claude, terminal (Ghostty, Terminal, iTerm ou comando próprio) e pastas ficam em Ajustes › Claude.

Roda no seu Mac e fala só com o GitHub.

Token no Keychain

Usa o gh auth token que você já tem, ou um token com os escopos repo e read:org. Nada vai para arquivo nem para servidor nosso.

Sem conta, sem backend

A API do GitHub é consultada direto do seu Mac. O último estado fica em ~/Library/Application Support/PRumo.

Funciona com SSO

Org com SAML não autorizado não derruba o app: os PRs que dá para ler continuam aparecendo.

Como instalar

Por enquanto o PRumo é compilado a partir do código e roda assinado localmente, sem passar pela App Store.

  1. Tenha o básico

    macOS 26, Xcode 27, brew install xcodegen gh e o GitHub CLI logado com gh auth login. Para as ações do Claude, o Claude Code disponível no shell como claude.

  2. Compile
    xcodegen generate
xcodebuild -project PRumo.xcodeproj -scheme PRumo -destination 'platform=macOS' build
  3. Abra e conecte

    O app encontra o seu gh, pede permissão de notificação e oferece abrir junto com o macOS. Na primeira leitura nada vira aviso.
